# DoD-Checkliste: SW-Anforderung (v1, Sprint 2, T-0021)

*Anwendung: QM/RM-Review je SWR vor Status `reviewed`; abgeleitet aus Playbook Kap. 6.*

- [ ] Eindeutige ID (`SWR-xxx`), nie wiederverwendet
- [ ] Eindeutig und atomar: genau ein prüfbares Verhalten („shall", keine Und-Ketten unterschiedlicher Verhalten)
- [ ] Testbar formuliert (beobachtbares Verhalten, keine Absichtserklärung)
- [ ] Attribute vollständig: Trace, Verification, Prio, Status
- [ ] Trace auf mindestens eine STK-Quelle vorhanden und plausibel
- [ ] Verifikationskriterium benannt (konkreter Test/Check, nicht „wird getestet")
- [ ] Sprache Englisch (D011)
- [ ] Reviews: machbar (ARCH/DEV-Kontext), prüfbar (TEST/QM), QM-Check ok
