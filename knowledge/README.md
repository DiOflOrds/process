# Wissensbasen der Rollen (Lernzyklus)

Je Rolle ein Verzeichnis (`pl/`, `cm/`, `coach/`, …) mit:

- `lessons.md` — kuratierte Lessons Learned (nummeriert, mit Datum und Quelle/Ticket)
- `gold-beispiele/` — Referenz-Ein-/Ausgaben; dienen als Regressionstest vor jedem Wissensbasis-Update
- `heuristiken.md` — rollenspezifische Faustregeln und bekannte Fallstricke

Regeln (Playbook Kap. 11): Updates nur per Prozess-CR mit Review (betroffene Rolle + QM) und bestandenem Gold-Beispiel-Regressionstest. Größenbudget je Rolle: max. ~2.000 Wörter lessons+heuristiken — Kuratieren heißt auch Löschen. Wirkung wird im Folgesprint an First-Pass-Yield und Nacharbeitsquote gemessen; bei Verschlechterung Revert.
